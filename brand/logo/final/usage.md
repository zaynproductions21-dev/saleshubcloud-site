# SalesHub Cloud logo: usage

Every file here is generated by `build.py` from one geometry: the squared S, followed by Archivo 800 "alesHub" and Archivo 400 "Cloud", all outlined. Never retype the name in a font next to the S.

```bash
python build.py            # rebuild the files in this folder
python build.py --install  # also copy favicon.ico, icon.svg and apple-touch-icon.png to the site root and update every page
```

The script needs fonttools, uharfbuzz and pillow, and Google Chrome for the PNGs. The fonts are in `../fonts` (OFL).

## Files

| File | Use |
|---|---|
| `logo.svg` | The wordmark on light grounds: ink `#2F2B3D` with the lower half of the S in `#099C99`. |
| `logo-reversed.svg` | On dark grounds: white with the lower half of the S in `#0BAEAB`. |
| `logo-mono-black.svg` / `logo-mono-white.svg` | Print, fax, embossing, any one-colour use. |
| `logo-name-only.svg` | "SalesHub" without "Cloud", for the app sidebar and tight spaces. |
| `logo-inline.svg` | What the site embeds. Its ink is `currentColor` and its accent is `var(--accent)`, so it follows the theme. |
| `logo@2x.png` | 1200px raster for documents and emails that cannot take SVG. |
| `mark.svg`, `mark-mono.svg`, `mark-reversed.svg` | The S on its own, on a 48-unit grid. |
| `icon.svg` | The SVG favicon. It switches to white and `#0BAEAB` in a dark browser tab. |
| `favicon.ico` | 16, 32 and 48px. |
| `apple-touch-icon.png` | 180px: the reversed mark on a solid `#28243D` ground. |
| `mark-512.png` | Social avatars and app stores. |

## Colours

- Ink `#2F2B3D` (the site's text colour); dark ground `#28243D`.
- Accent on light `#099C99`: 3.37:1 on white, which passes the 3:1 a graphic needs. The brighter brand teal `#0BAEAB` is only 2.74:1 on white, so it is used **only on dark grounds** (5.43:1 on `#28243D`).
- Only the lower half of the S is ever teal. Never colour the rest of the name.

## Clear space and sizes

- Clear space on every side = the S's stroke width (about one fifth of the cap height).
- The wordmark is never shorter than **16px** tall on screen or **6mm** in print. Use `logo-name-only.svg` below 18px.
- The mark is never smaller than **16px**.
- On the site the wordmark is 20px tall in the nav, 18px on phones and 22px in the footer (`#sh-logo-css` on each page).

## Do / don't

- **Do** use the wordmark alone, or the mark alone. **Don't** put the mark next to the wordmark: "S SalesHub" doubles the S.
- **Don't** stretch, outline, add a shadow, gradient or tile behind the mark, or swap the colours of the two halves.
- **Don't** set "SalesHub Cloud" in Public Sans (or any live font) beside the S. Use the outlined files.
- **Don't** bring back the old concentric circles anywhere, including emails and the app.
